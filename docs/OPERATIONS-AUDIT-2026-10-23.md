# 운영 누락 점검 · 2026-10-23

## 확인한 문제와 조치

- GitHub 원격에는 `main`만 있었고 미반영 PR은 없었다. 마지막 인계 커밋 `8cf01e9154e9140c25ad62d0b47891bea9969204`까지 푸시되어 Vercel 배포가 성공한 상태였다.
- 운영 DB에는 `20261026000000_feedback_hardening.sql`의 표·인덱스·함수·트리거·정책 12개가 전부 미적용이었다. 고객 의견을 저장할 수 없었고 새 접수 정보 보호도 빠져 있었다.
- 사용자가 온답 계정의 CLI `ondap` 프로필에 로그인하고 운영 DB 적용을 명시적으로 승인했다. 기존 마이그레이션을 `BEGIN`/`COMMIT` 안에서 적용했다. 기존 데이터 삭제·수정은 수행하지 않았다.
- 별도 연결에서 구성요소 12개와 의견 추가 권한·익명 조회를 차단하는 RLS 정책 등 4개를 재확인했다. 조회용 SQL은 [feedback-hardening.sql](../supabase/checks/feedback-hardening.sql)에 보관했다. 이미 적용된 마이그레이션을 다시 실행하지 않는다.
- 주문서 테스트는 임시 안내 띠가 나온 즉시 검사를 시작하고 있었다. 서버에서 포장 요약이 도착할 때까지 기다리도록 수정했다.
- 관리자 점수 예시 테스트는 합성 이벤트 대신 Chrome의 실제 입력 경로로 글을 넣도록 수정했다. 저장과 상품 편집기 도움말 반영을 확인했다.
