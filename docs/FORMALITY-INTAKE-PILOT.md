# 격식지수 v2 로컬 시험 및 업무 흐름 안내

`npm run dev:pilot` (또는 `npm run dev`) 실행 후 **http://127.0.0.1:3000/admin/formality** 를 연다.
특허출원서 구조(행사 분석부 → 상품 속성 평가부 → 매칭 필터부 → 상품 추천부)에 맞춰 상품 정보를 이해·평가하고 행사별 적합성을 검증하는 전체 업무 흐름이 하나의 화면에서 제공된다.

* 같은 폴더에서 개발 서버는 하나만 실행한다 (`127.0.0.1:3000` 사용).
* `dev:pilot`은 로컬 모드를 사용한다. Supabase 운영 환경에서는 관리자 인증을 거쳐 상품 근거를 운영 DB에 저장한다.
* 새 엔진은 고객 추천(`/result`)을 교체하지 않는다. 운영에서 상품 가져오기를 누르면 기존 운영 상품 목록이 갱신된다.

---

## 관리자 업무 흐름 (확인 순서)

### 1단계: 상품 선택 및 설명 불러오기
1. 좌측 목록에서 상품을 선택하거나, **[카페24 상품 가져오기]**로 최신 상품 목록을 불러온다.
   - 카페24 API 연결이 실패하거나 미설정 상태여도 기존 로컬 카탈로그(40개)가 안전하게 보존된다.
2. **[카페24 설명 가져오기]**로 등록된 상세 설명을 읽어온다.
   - 이미지로만 구성된 상세페이지 등 텍스트가 없는 경우 원인이 명확히 표시된다.
   - 생산자 이력, 산지, 제작방식 등 확인한 원문을 직접 입력·보완할 수 있다.

### 2단계: AI 정보 정리 및 5대 희소 속성 검토
1. **[Gemini AI로 정보 정리]**를 누르면 상품 원문에서 5대 희소 속성에 해당하는 근거 문장을 추출한다.
   - 기존 Gemini API와 운영 모델 설정을 그대로 사용한다.
   - 원문에 실제 존재하는 문장만 근거로 채택한다(`source.includes(basis)`). 해석과 수준은 운영자가 확인한다.
   - 원문에 없는 항목은 '미확인' 상태로 남겨둔다.
2. 운영자가 5개 속성의 수준(일반 2점, 일부 특징 5점, 뚜렷한 특징 8점)과 근거 내용을 직접 검토·수정한다.
   - 생산자 숙련도 (skill)
   - 지역적 희소성 (locality)
   - 유통 제한성 (distribution)
   - 역사성 (history)
   - 지역 스토리 (story)

### 3단계: 상품 희소 속성값 계산 및 저장
1. 근거가 명시된 속성이 2개 이상일 때 **[확인하고 계산하기]**를 눌러 검수를 완료한다.
   - 5개 속성 중 유효 근거의 가중평균으로 상품 희소 속성값(0~100점)이 산출된다.
   - 근거가 2개 미만인 경우 기준 충족 전까지 검수 완료가 차단된다.
2. 저장 내용은 `data/formality-pilot.json`에 안전하게 기록되며, **새로고침 후에도 유지**된다.

### 4단계: 개별 상품의 행사 적합성 시험 (허용기준 필터)
1. 검수가 완료된 상품에 대해 하단 **[행사 적합성 시험]** 영역이 활성화된다.
2. 행사 종류(12종), 관계(4종), 발신 주체(5종), 행사 목적(6종)을 선택하고 **[행사 적합성 확인]**을 누른다.
3. 결과 확인:
   - 행사 격식 점수(0~100점) 및 해당 행사 격식 구간의 허용 희소값 범위(하한~상한)
   - 상품 희소값과 비교하여 **[기준 충족 (적격 후보)]** 또는 **[기준 미충족 (후보 제외)]** 판정
   - 제외 시 구체적 사유(희소값 미달/초과, 품절/미진열, 행사 제외 등) 표시
   - 발신 주체나 목적이 미입력인 경우 경고 안내.

### 5단계: 전체 시뮬레이션 및 순위 평가 검증실 (Lab)
1. 상단 우측의 **[격식 기준 검증실 →]** (`/admin/formality/lab`)을 열어 전체 카탈로그에 대한 결과를 확인한다.
2. 자료 선택에서 **'현재 카탈로그'**를 선택하면 앞서 검수한 상품 근거가 즉시 주입된다.
3. 32개 행사 시나리오 전체에 대해:
   - 1차 매칭 필터: 허용기준을 충족하지 못한 상품 제외 (미검수, 근거 부족, 희소값 미달 등)
   - 2차 순위 평가: 적격 후보에 대해서만 가격 실속, 신뢰/안전, 실용성 가중평균으로 순위 평가
   - 카테고리 다양성을 반영한 최종 추천 1~3위 선정
   - 적격 후보가 부족한 경우 기준을 조용히 완화하지 않고 경고 안내 유지
4. 기준표 편집기를 통해 행사 기본점수, 보정치, 구간표, 희소/순위 가중치를 조정하고 JSON 파일로 내보내기/불러오기 가능.

## 저장 방식 및 운영 전환 대비

  - 현재 운영 DB에는 적용하지 않았으며, 향후 운영 전환 승인 시 Supabase SQL Editor에서 실행합니다.
  - 되돌리기(롤백): `drop table if exists public.product_evidence, public.formality_policies cascade;`
