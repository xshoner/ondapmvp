## 시스템 구성

**□ 전체 흐름**

![G-21](C:/Users/xshon/Desktop/ondapmvp-report/docs/report/build/img/G-21.png)
@@CAPTION <그림 G-21> 전체 흐름도 (고객 → 추천 → 포장 → 카페24 주문 → 관리자 인쇄)
@@SPACER

- 고객 → 추천 → 포장 → 주문 → 제작의 다섯 단계가 하나로 이어지도록 구성함
  - **추천**: 고객이 행사·받는 분·예산·수량을 고르면, 추천 엔진이 격식지수와 예산 적합도로 상품 3개(표준안·실속안·격식안)를 제시함
  - **포장**: 고른 상품에 포장지·스티커·카드 문구를 꾸며 저장하면 디자인 코드(OD-XXXX-XXXX)가 발급됨
  - **주문**: 카페24 쇼핑몰 상품 페이지로 이동하면 쇼핑몰 도우미가 수량을 맞추고, 주문서에 디자인 코드를 자동으로 입력함
  - **확인**: 결제가 끝나면 카페24가 알림(웹훅)을 보내고, 시스템이 주문과 디자인 접수를 자동으로 연결함
  - **제작**: 관리자가 인쇄 파일(PDF, QR 포함)을 내려받아 인쇄하고, 완성품의 QR을 찍어 "인쇄 완료"로 처리함
- 기관·기업 고객은 추천 결과에서 바로 결재 문서(지출결의·품의서)를 만들어 한글·워드·PDF로 내려받을 수 있음

    - 2. 저장한 디자인 목록 또는 코드 조회 영역을 확인함.
    - 3. 필요한 디자인의 진행 상황을 확인함.
    - 4. 필요하면 **다시 꾸미기** 또는 **인쇄물 그림 받기**를 누름.
- 유의사항: 기기에 저장된 목록과 그림은 기기 변경이나 저장자료 삭제에 따라 보이지 않을 수 있음.

**□ 계정·보안 원칙**

- 비밀번호·연동 키는 문서·메신저·이메일로 주고받지 않고, 각 서비스의 관리 화면에서만 다룸
- 관리자 비밀번호는 관리자 화면 "비밀번호 변경"에서 주기적으로 바꿈
- 쇼핑몰 스킨(화면 디자인) 수정은 저장 즉시 실제 쇼핑몰에 반영되므로, 도우미 스크립트 부분은 지우지 않도록 주의
- 소스 저장소의 main 브랜치는 곧 운영 사이트이므로, 수정은 다른 브랜치에서 검증한 뒤에만 반영함
- 데이터베이스 구조 변경은 저장소의 변경 파일을 데이터베이스 관리 화면에서 순서대로 실행함

## 향후 과제 및 제언

- 추천 대상 상품 검수 확대 (최우선)
  - 현황: 2026-11-28 운영 사이트에서 대부분 조건의 추천 결과가 1개만 나오는 것으로 확인됨. 2026-11-11 쇼핑몰 전환 이후 격식지수 근거 검수를 마친 상품이 적기 때문으로 추정됨.
  - 제안: 판매 중 상품의 격식지수 근거 입력과 검수를 마쳐 조건별 표준·실속·격식 3안을 제시할 수 있도록 함.
  - 기대효과: 고객이 조건에 맞는 선택지를 비교할 가능성을 높임.

- 서비스 계정 정리
  - 현황: 웹 서버(서비스 화면을 제공하는 컴퓨터)와 데이터베이스(자료 저장소) 계정의 요금제와 소유 명의를 운영 단계에 맞게 확정할 필요가 있음.
  - 제안: 상업 운영에 맞는 요금제를 검토하고 고객사 명의로 이전함.
  - 기대효과: 서비스 운영 책임과 계정 관리 주체를 명확히 함.

- 추천 기준 검토
  - 현황: 행사·관계별 기준과 기대 상품을 관리자가 조정할 수 있음.
  - 제안: 32개 시나리오와 고객 의견을 함께 검토하여 기준을 조정함.
  - 기대효과: 행사별 추천 결과의 일관성을 점검할 수 있음.

- 쇼핑몰 연계 점검
  - 현황: 수량·옵션·디자인 코드의 자동 연결을 시도하며 쇼핑몰 환경에 영향을 받음.
  - 제안: 쇼핑몰 변경 후 상품 상세부터 주문서까지 비회원 흐름을 점검함.
  - 기대효과: 주문과 포장 접수 간 불일치를 줄임.

- 운영 인계와 기록 관리
  - 현황: 접수, 인쇄 및 운영상태 확인 기능이 제공됨.
  - 제안: 담당자와 점검 주기, 장애 대응 및 권한 관리 책임을 확정함.
  - 기대효과: 담당자 변경이나 장애 발생 시 업무 연속성을 높임.

- 사업 성과 확정
  - 현황: 대시보드에 조회·접수 등 기간별 집계 기능이 있으나, 운영 기간이 짧아 성과 지표의 기준이 아직 정해지지 않음.
  - 제안: 집계 기간과 지표 정의를 확정하고 운영 자료를 대조함.
  - 기대효과: 결과보고서의 수치를 검증 가능하게 제시함.

## 부록 A. 용어 풀이

- 격식지수: 상품의 확인된 속성과 근거를 바탕으로 살펴보는 격식 수준의 점수임.
- 추천점수: 격식지수와 행사·관계·예산 등 조건을 반영하여 추천 순위를 정하는 점수임.
- 가중치: 여러 판단 기준 가운데 특정 기준을 얼마나 반영할지 정하는 비중임.
- 관계 보정: 받는 분과의 관계에 따라 상품 적합도를 조정하는 기준임.
- 시나리오 검증: 행사와 관계를 조합한 상황별 추천 결과를 살펴보는 점검임.
- 기대 정답: 특정 상황에서 관리자가 적절하다고 지정한 기대 상품임.
- 디자인 코드: 저장한 포장 디자인을 주문과 연결하거나 진행 상황을 조회하는 OD-XXXX-XXXX 형식의 코드임.
- 카페24 도우미: 쇼핑몰 화면에서 포장 버튼과 수량·디자인 코드 전달을 지원하는 프로그램임.
- 포장 접수: 고객이 저장한 포장 및 인쇄물 디자인을 관리자가 처리할 수 있도록 남긴 기록임.
- QR 코드: 카메라로 읽어 관련 화면을 열 수 있는 사각형 표시임.
- 결재 문서: 지출결의 또는 품의에 활용할 수 있도록 상품과 금액을 담아 만드는 초안임.
- CSV: 표 형태의 자료를 다른 프로그램에서 열 수 있도록 저장하는 파일 형식임.
- 배포: 만든 프로그램을 이용자가 접속할 수 있는 환경에 반영하는 과정임.
- 데이터베이스: 상품, 설정, 접수 등 업무 자료를 보관하고 조회하는 저장 공간임.
