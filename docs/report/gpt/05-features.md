# [S-5] 주요 기능 소개 및 사용법

## 5.1 고객 기능

### [F-01] 조건 입력

○ 개요: 행사, 받는 분과의 관계, 예산과 수량을 입력하여 답례품을 찾음. 지난 조건과 찜한 답례는 해당 기기에서 다시 확인할 수 있음.
○ 화면: [그림 G-01]
○ 사용 방법
1. 행사 항목에서 자리를 선택함.
2. 받는 분과의 관계를 선택함.
3. 예산 방식과 금액을 선택함.
4. 수량을 입력함.
5. **답례품 추천받기**를 누름.
○ 유의사항: 지난 조건과 찜 목록은 사용한 기기의 저장 상태에 따라 달라짐.

### [F-02] 추천 결과

○ 개요: 조건에 맞는 상품을 추천점수와 함께 제시함. 조건 변경, 추천 제외, 찜, 공유 및 의견 제출을 지원함.
○ 화면: [그림 G-02] [그림 G-03] [그림 G-04]
○ 사용 방법
1. 추천 상품과 예상 합계를 확인함.
2. **추천점수는 어떻게 나왔나요?**를 눌러 설명을 확인함.
3. 필요하면 **조건 바꾸기**를 눌러 조건을 조정함.
4. 필요하면 **이 상품은 추천에서 제외하기**를 누름.
5. **상품 보기·주문** 또는 **포장·스티커 꾸미기(유료)**를 선택함.
○ 유의사항: 조건에 맞는 상품이 부족하면 결과는 3개보다 적을 수 있음. 배송비와 최종 가격은 쇼핑몰에서 확인함.

### [F-03] 포장·스티커 꾸미기

○ 개요: 포장지와 스티커 또는 카드의 문구·이미지를 선택하고 완성 모습을 확인함. 저장하면 디자인 코드가 발급됨.
○ 화면: [그림 G-05] [그림 G-06] [그림 G-07]
○ 사용 방법
1. 추천 결과에서 **포장·스티커 꾸미기(유료)**를 누름.
2. 포장지와 인쇄물 종류를 선택함.
3. 문구와 필요한 이름을 입력하고 미리보기를 확인함.
4. **다음: 최종 확인**을 누름.
5. 제작 전 확인 사항을 확인하고 **디자인 완료하고 코드 받기**를 누름.
6. 발급된 코드를 확인하고 **주문하러 가기**를 누름.
○ 유의사항: 포장·인쇄는 유료 서비스임. 글자 잘림과 이름 철자, 수량 및 최종 금액을 확인함.

### [F-04] 내 디자인

○ 개요: 이 기기에 저장된 디자인을 확인하거나 디자인 코드로 진행 상황을 조회함. 같은 디자인으로 다시 주문하거나 인쇄물 그림을 받을 수 있음.
○ 화면: [그림 G-08]
○ 사용 방법
1. 첫 화면에서 **내 디자인**을 누름.
2. 저장한 디자인 목록 또는 코드 조회 영역을 확인함.
3. 필요한 디자인의 진행 상황을 확인함.
4. 필요하면 **다시 꾸미기** 또는 **인쇄물 그림 받기**를 누름.
○ 유의사항: 기기에 저장된 목록과 그림은 기기 변경이나 저장자료 삭제에 따라 보이지 않을 수 있음.

### [F-05] 카페24 쇼핑몰 연동

○ 개요: 상품 상세에서 포장 편집을 열고 저장한 디자인의 수량·옵션 및 코드를 쇼핑몰 주문으로 전달하도록 지원함.
○ 화면: [그림 G-09] [그림 G-10]
○ 사용 방법
1. 디자인 저장 후 **주문하러 가기**를 누름.
2. 상품 상세에서 포장 옵션과 수량을 확인함.
3. **BUY IT NOW**를 누르고 필요하면 **비회원 구매**를 선택함.
4. 주문서의 **답례큐 포장 디자인 코드**와 포장 요약을 확인함.
5. 코드가 비어 있으면 발급받은 코드를 직접 입력함.
○ 유의사항: 자동 선택과 입력은 쇼핑몰 환경에 따라 달라질 수 있음. 최종 수량과 금액을 주문서에서 확인함.

### [F-06] 결재 문서

○ 개요: 추천 상품과 수량을 바탕으로 지출결의·품의서 초안을 작성하고 검토·편집 및 파일 내려받기를 지원함.
○ 화면: [그림 G-11] [그림 G-12]
○ 사용 방법
1. 추천 결과에서 **결재 문서 만들기**를 누름.
2. 문서에 반영할 내용을 확인함.
3. 결재 문서 검토·편집 화면에서 필요한 항목을 수정함.
4. 미리보기로 내용을 확인함.
5. 원하는 형식의 문서 파일을 내려받음.
○ 유의사항: 초안의 금액과 문구는 제출 전 담당자가 검토해야 함. 비공개 초안은 작성한 브라우저에서 열람함.

## 5.2 관리자 기능

### [F-07] 대시보드

○ 개요: 오늘 처리할 접수와 기간별 추천·주문·인쇄 실적을 살펴보고 자료를 내려받거나 인쇄함.
○ 화면: [그림 G-13]
○ 사용 방법
1. 관리자 화면에 로그인함.
2. 대시보드의 오늘 할 일을 확인함.
3. 조회할 기간을 선택하고 **기간 적용**을 누름.
4. 실적과 결재 문서 생성 수를 확인함.
5. 필요하면 **일별 CSV 내려받기** 또는 **A4로 인쇄**를 누름.
○ 유의사항: 집계 기간과 자료 연결 상태를 확인함. 결재 문서 지표는 기능 설정에 따라 표시됨.

### [F-08] 격식지수 판정

○ 개요: 상품의 5가지 속성에 대한 자료와 점수를 검토하여 판정하고 검수함.
○ 화면: [그림 G-14]
○ 사용 방법
1. 관리자 메뉴에서 **격식지수 판정**을 누름.
2. 판정할 상품을 선택함.
3. 확인된 속성별 근거와 수준을 입력함.
4. 필요하면 **임시 저장 (미검수)**을 누름.
5. 근거를 검토한 후 **격식지수 판정하기 (검수 완료)**를 누름.
○ 유의사항: 근거가 있는 속성이 2개 이상 필요함. 모르는 항목은 미확인으로 남김.

### [F-09] 가중치 설정

○ 개요: 행사별 기준과 관계 보정 등 추천에 적용되는 설정을 조정함. 변경 전후 결과를 살펴볼 수 있음.
○ 화면: [그림 G-15]
○ 사용 방법
1. 관리자 메뉴에서 가중치 설정 화면을 엶.
2. 행사별 기준과 관계 보정값을 확인함.
3. 필요한 값을 수정함.
4. 변경 전후의 결과를 확인함.
5. **기준 저장**을 누름.
○ 유의사항: 저장된 기준은 고객 추천과 검증에 적용되므로 변경 전후 결과를 검토함.

### [F-10] 알고리즘 검증

○ 개요: 행사 8개와 관계 4개의 조합을 살펴보고 기대 상품과 실제 추천 결과를 비교함.
○ 화면: [그림 G-16]
○ 사용 방법
1. 관리자 메뉴에서 알고리즘 검증 화면을 엶.
2. 행사와 관계별 시나리오 결과를 확인함.
3. 확인할 시나리오를 선택함.
4. 필요한 경우 기대 상품을 지정함.
5. 일치 여부와 상세 결과를 검토함.
○ 유의사항: 기대 상품 지정 여부와 상품 검수 상태에 따라 결과 해석이 달라짐.

### [F-11] 포장 디자인 및 접수

○ 개요: 포장지와 추천 이미지·문구·배너를 관리하고 디자인 접수, 주문 연결 및 인쇄 파일을 처리함.
○ 화면: [그림 G-17] [그림 G-18]
○ 사용 방법
1. 관리자 메뉴에서 포장 디자인 화면을 엶.
2. 접수 목록에서 디자인 코드 또는 상태를 확인함.
3. 접수 상세에서 문구와 주문 정보를 검토함.
4. 해당 주문번호를 연결함.
5. **시험 인쇄 1장** 또는 **인쇄 PDF 받기**를 이용함.
○ 유의사항: 주문과 디자인 코드·수량을 대조하고 인쇄 전 문구와 재단 영역을 확인함.

### [F-12] QR 스캔 인쇄 완료 처리

○ 개요: 인쇄물에 포함된 QR 코드로 해당 접수를 찾아 인쇄 완료 상태를 처리함.
○ 화면: [그림 G-19]
○ 사용 방법
1. 관리자 메뉴에서 **QR 스캔**을 누름.
2. 화면 안내에 따라 QR 코드를 읽음.
3. 표시된 디자인과 상태를 확인함.
4. 인쇄 완료 처리를 확인함.
○ 유의사항: 카메라 사용 권한이나 로그인 상태가 필요할 수 있음. 잘못 처리한 경우 화면의 되돌리기 기능을 확인함.

### [F-13] 운영상태 점검

○ 개요: 자료 연결과 작업 기록 등 운영 상태를 확인하여 점검이 필요한 항목을 찾음.
○ 화면: [그림 G-20]
○ 사용 방법
1. 관리자 메뉴에서 운영상태 화면을 엶.
2. 표시된 연결 및 작업 상태를 확인함.
3. 오류 또는 확인이 필요한 항목의 안내를 읽음.
4. 필요한 조치 후 상태를 다시 확인함.
○ 유의사항: 오류가 표시되면 정상으로 간주하지 않고 담당자가 연결과 설정을 점검함.
