## [S-2] 2. 시스템 구성

### [S-2.1] 전체 흐름

[그림 G-21]

○ 고객 → 추천 → 포장 → 주문 → 제작의 다섯 단계가 하나로 이어지도록 구성함
  - **추천**: 고객이 행사·받는 분·예산·수량을 고르면, 추천 엔진이 격식지수와 예산 적합도로 상품 3개(표준안·실속안·격식안)를 제시함
  - **포장**: 고른 상품에 포장지·스티커·카드 문구를 꾸며 저장하면 디자인 코드(OD-XXXX-XXXX)가 발급됨
  - **주문**: 카페24 쇼핑몰 상품 페이지로 이동하면 쇼핑몰 도우미가 수량을 맞추고, 주문서에 디자인 코드를 자동으로 입력함
  - **확인**: 결제가 끝나면 카페24가 알림(웹훅)을 보내고, 시스템이 주문과 디자인 접수를 자동으로 연결함
  - **제작**: 관리자가 인쇄 파일(PDF, QR 포함)을 내려받아 인쇄하고, 완성품의 QR을 찍어 "인쇄 완료"로 처리함
○ 기관·기업 고객은 추천 결과에서 바로 결재 문서(지출결의·품의서)를 만들어 한글·워드·PDF로 내려받을 수 있음

### [S-2.2] 구성 요소

| 구분 | 구성 요소 | 하는 일 |
| --- | --- | --- |
| 고객 화면 | 조건 입력, 추천 결과, 포장 꾸미기, 내 디자인, 결재 문서 | 휴대폰 우선 화면. 로그인 없이 사용 |
| 추천 엔진 | 격식지수 판정 기준, 행사별 가중치, 추천점수 계산 | 같은 조건이면 언제나 같은 결과를 냄(동점일 때 정해진 순서로 가름) |
| 포장 디자인 | 포장지·추천 이미지·추천 문구, 스티커·카드·엽서 편집기, 인쇄 파일 생성 | 디자인 코드 발급, A4·A3 인쇄 PDF와 QR 생성 |
| 카페24 연동 | 쇼핑몰 도우미 스크립트, 상품 동기화, 결제 알림 수신, 주문 조회 | 쇼핑몰 화면에 버튼·자동 입력 추가, 주문과 디자인 자동 연결, 취소 반영 |
| 관리자 화면 | 대시보드, 격식지수 판정, 가중치, 알고리즘 검증, 포장 접수, QR 스캔, 운영상태 | 로그인한 관리자만 사용 |
| 결재 문서 | 문서 초안 저장, 검토·편집, 한글(HWPX)·워드(DOCX)·PDF 출력 | 추천 당시 상품·수량·금액을 그대로 문서에 담음 |
| 자동 작업 | 매일 1회 상품 동기화·운영 점검·임시 파일 정리 | 매일 18:00(한국 시간) 자동 실행 |
| AI 보조 | 격식지수 근거를 바탕으로 한 점수 제안 (Google Gemini) | 제안만 하고, 저장은 관리자가 확인한 뒤에만 함 |

### [S-2.3] 운영 환경

| 항목 | 내용 |
| --- | --- |
| 서비스 주소 | https://dapcue.vercel.app (관리자: /admin) |
| 연동 쇼핑몰 | https://dapcue.cafe24.com (2026-11-11 이전에는 시험 쇼핑몰 axopenlab) |
| 웹 서버(호스팅) | Vercel, 서울 지역(icn1), Node.js 24 |
| 데이터베이스·파일 저장소 | Supabase (PostgreSQL, 서울 지역) |
| 화면 기술 | Next.js 16 (React 기반 웹 프레임워크) |
| 소스 저장소 | GitHub `xshoner/ondapmvp` — `main` 브랜치에 올리면 운영 사이트에 자동 배포됨 |
| 쇼핑몰 연동 방식 | 카페24 앱(운영자 동의로 설치) + 쇼핑몰 화면에 붙인 도우미 스크립트 |
| 보안 원칙 | 비밀 키는 서버 환경 변수에만 보관, 데이터베이스는 행 단위 접근 규칙(RLS)으로 관리자·고객 권한 분리, 관리자 화면은 로그인 확인 후에만 열림 |

### [S-2.4] 데이터 구성

| 데이터 | 내용 |
| --- | --- |
| 상품 | 카페24에서 매일 가져오는 상품명·가격·진열·판매·품절·이미지 |
| 상품 판정 자료 | 상품별 격식지수 근거와 점수, 검수 여부, 변경 이력 |
| 엔진 설정 | 행사별 가중치, 관계별 보정, 보너스, 예산 확대 규칙 |
| 시나리오 기대 정답 | 행사 8 × 관계 4 = 32개 조합의 기대 추천 |
| 추천 기록·고객 의견 | 추천 조건과 결과, "도움 됐어요/아쉬워요" 의견 (개인 정보 없음) |
| 포장 자산 | 포장지, 추천 이미지, 추천 문구, 쇼핑몰 메인 배너 |
| 디자인 접수 | 디자인 코드, 상품·수량, 편집 내용, 진행 상태, 연결된 주문 |
| 결제 알림 | 카페24 결제·취소 알림 기록(중복 처리 방지) |
| 결재 문서 | 문서 초안, 편집 내용, 상품 이미지 사본 |
