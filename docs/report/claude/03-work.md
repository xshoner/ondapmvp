### [S-3.1] 추천 엔진 (격식지수)

| 작업 | 내용 | 상태 |

| 격식지수 엔진 v2 | 행사가 요구하는 격식 수준과 상품의 희소성·특성을 나누어 판정하는 구조로 재설계, 근거 자료를 검수한 상품만 추천 | 완료 (10/28~11/01) |

| 추천점수 | 행사 적합도와 예산 대비 가격을 합친 최종 점수, 고객용 설명 제공 | 완료 (11/02~11/08) |

| 32개 시나리오 검증 | 행사 8 × 관계 4 조합마다 기대 정답을 정하고 일치율을 자동 계산 | 완료 |
| AI 점수 제안 | Google Gemini가 상품 근거를 읽고 점수를 제안(저장은 사람이 확인 후), 응답 지연·혼잡 시 대체 모델로 전환 | 완료 (10/20, 11/26 기본 모델 교체) |
