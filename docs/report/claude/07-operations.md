## [S-7] 7. 운영 안내

### [S-7.1] 관리자 일상 업무

| 때 | 할 일 | 화면 |
| --- | --- | --- |
| 매일 아침 | 대시보드 "오늘 할 일"에서 주문 확인 대기·인쇄 대기·지연 건 확인 | 관리자 → 대시보드 |
| 주문이 들어오면 | 결제가 끝난 주문은 자동으로 디자인과 연결됨. 연결되지 않았거나 확인이 필요한 건만 접수 목록에서 처리 | 포장 디자인 및 접수 |
| 인쇄할 때 | 인쇄 대기 건의 인쇄 PDF(A4·A3)를 내려받아 인쇄. 처음이면 "시험 1장"으로 먼저 확인 | 포장 디자인 및 접수 |
| 포장을 마치면 | 인쇄물의 QR을 찍어 "인쇄 완료"로 처리. 휴대폰 카메라 앱으로 찍어도 됨 | QR 스캔 |
| 상품이 바뀌면 | 카페24 상품은 매일 자동으로 가져옴. 새 상품은 격식지수 근거·점수를 입력하고 검수해야 추천에 나옴 | 격식지수 판정 |
| 추천이 이상하면 | 32개 시나리오 일치율 확인, 필요하면 가중치 조정 후 전후 미리보기로 확인 | 알고리즘 검증, 가중치 설정 |
| 행사철이 바뀌면 | 포장지·추천 문구·쇼핑몰 메인 배너 교체 | 포장 디자인 및 접수 |
| 문제가 의심되면 | 데이터베이스·쇼핑몰·자동 작업 연결 상태 확인 | 운영상태 |
| 실적 보고 | 기간을 골라 CSV 내려받기 또는 A4 인쇄 | 대시보드 |

### [S-7.2] 문제가 생겼을 때

| 상황 | 조치 |
| --- | --- |
| 새로 배포한 뒤 화면이 이상함 | Vercel 관리 화면 → Deployments에서 직전 정상 배포를 골라 "Promote to Production"을 누르면 몇 초 안에 이전 버전으로 돌아감 |
| 주문과 디자인이 연결되지 않음 | 접수 목록에서 카페24 주문 상세를 붙여 넣어 주문번호를 직접 연결 |
| 고객 주문서에 디자인 코드가 자동으로 안 들어감 | 고객이 디자인 저장 화면의 "코드 복사하기"로 직접 붙여 넣도록 안내. 쇼핑몰 스킨에 도우미 스크립트가 남아 있는지 확인 |
| 카페24 연결이 끊김(상품·주문을 못 가져옴) | 운영상태 화면에서 확인 후, 카페24 앱 연결을 다시 승인 |
| 부분 취소 주문 | 접수 목록의 "확인 필요" 표시 건을 검토한 뒤 관리자가 취소를 확정 |

### [S-7.3] 계정·보안 원칙

○ 비밀번호·연동 키는 문서·메신저·이메일로 주고받지 않고, 각 서비스의 관리 화면에서만 다룸
○ 관리자 비밀번호는 관리자 화면 "비밀번호 변경"에서 주기적으로 바꿈
○ 쇼핑몰 스킨(화면 디자인) 수정은 저장 즉시 실제 쇼핑몰에 반영되므로, 도우미 스크립트 부분은 지우지 않도록 주의
○ 소스 저장소의 `main` 브랜치는 곧 운영 사이트이므로, 수정은 다른 브랜치에서 검증한 뒤에만 반영함
○ 데이터베이스 구조 변경은 저장소의 변경 파일을 데이터베이스 관리 화면에서 순서대로 실행함
