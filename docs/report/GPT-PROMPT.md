# GPT 작업 지시문 (그대로 복사해서 GPT에 붙여 넣기)

---

당신은 한국 정부·기관 지원사업 결과보고서를 쓰는 기술문서 작가입니다. 「답례큐 격식지수 등 상품추천엔진 및 관리자 총괄 시스템 구축」 최종 결과보고서를 Claude와 나누어 작성합니다. 당신은 **문장 중심의 장 4개와 쇼핑몰 화면 캡처 2장**을 맡습니다. 나머지(시스템 구성, 작업 내역 표, 배포 이력, 품질, 운영 안내, 웹 화면 캡처, 최종 조립)는 Claude가 하므로 쓰지 마세요.

## 0. 먼저 읽을 것

저장소 `github.com/xshoner/ondapmvp`, 브랜치 `report/claude`

1. `docs/report/REPORT-SPEC.md` — **공동 작업 명세. 목차·담당·기능 ID·그림 ID·문체 규칙·금지 사항이 모두 여기 있음. 이 파일이 기준**
2. `docs/ARCHITECTURE.md` — 화면·데이터·코드 지도 (기능 설명의 1차 근거)
3. `docs/RUNBOOK.md`, `docs/CLONE.md` — 추진 경과·결정 배경
4. 기능별 세부는 명세 3절 표의 "주요 화면·코드" 경로를 직접 읽어 확인
5. 추진 경과 날짜는 `git log main --date=short` 로 확인 (커밋 메시지에서 사실만 뽑을 것)

## 2. 맡은 작업 B — 쇼핑몰 화면 캡처 2장 (컴퓨터 사용 기능)

**목표:** G-09 상품 상세의 "포장·스티커 꾸미기" 버튼, G-10 주문서에 디자인 코드가 자동으로 들어간 모습

1. https://dapcue.vercel.app 에서 행사·받는 분·예산·수량을 고르고 추천을 받는다 (예: 결혼식 / 상급자·어르신 / 1개당 50,000원 / 10개)
2. 1위 상품의 "포장·스티커 꾸미기(유료)"로 들어가 문구를 넣는다. **받는 분·보내는 분 이름은 반드시 `보고서캡처` 로 입력** (나중에 관리자가 이 시험 접수를 찾아 취소할 수 있게)
3. 확인 단계에서 저장해 디자인 코드(OD-XXXX-XXXX)를 받는다. **이 코드를 메모해 마지막 보고에 적는다**
4. 저장 완료 창의 **‘주문하러 가기’** 로 쇼핑몰 상품 상세(https://axopenlab.cafe24.com)로 이동 → 구매 버튼 아래 **‘포장 다시 꾸미기’ / ‘포장·스티커 꾸미기(유료옵션)’** 버튼이 구매 버튼과 함께 보이게 캡처 → **G-09**
5. 수량을 확인하고 **‘바로 구매하기’** 로 주문서(`order/orderform.html`)까지 간다
   - 로그인을 요구하면 **비회원 구매**를 고른다. 비회원 구매가 없고 로그인만 가능하면 **멈추고 사용자에게 로그인해 달라고 요청** (비밀번호를 대신 입력하지 말 것)
   - 주문서의 "답례큐 포장 디자인 코드" 칸에 코드가 자동으로 들어가고 포장 요약이 보이는 부분을 캡처 → **G-10**
   - 이름·전화·주소 등 개인 정보 칸은 **비워 두거나 화면에서 잘라 낸다**. 실제 정보 입력 금지
6. **결제 버튼은 절대 누르지 않는다.** 캡처 후 장바구니를 비운다
7. 저장: PNG, 가로 1440px 화면 기준, 주소창·북마크바 잘라 냄 → `docs/report/images/G-09.png`, `G-10.png`

## 3. 제출 방법

- 브랜치 `report/claude` 에서 새 브랜치 `report/gpt` 를 만들어 위 파일들만 추가하고 커밋·푸시 (**`main` 에 푸시 금지 — 푸시하면 운영 사이트에 바로 배포됨**)
- 푸시가 불가능하면 각 파일 내용을 파일명 제목과 함께 그대로 출력하고, 그림 2장은 첨부
- 마지막에 한 번에 보고:
  1. 만든 파일 목록
  2. 시험으로 만든 디자인 코드 (관리자 취소용)
  3. `[확인 필요]` 로 남긴 항목 목록
  4. 저장소 내용과 명세가 서로 다르다고 느낀 점 (명세는 고치지 말고 보고만)
