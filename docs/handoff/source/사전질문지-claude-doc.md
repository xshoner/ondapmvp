# 온답(답례큐) 개발 사전 질문지

Oct 20, 2026 · @leechee

보내주신 서비스 소개, 화면 시안, 관리자 시안을 잘 받았습니다. 정확한 견적과 일정을 잡으려면 아래 질문에 대한 답이 필요합니다. 각 표의 **답변** 칸에 적어 주시고, 아직 정하지 못한 항목은 "미정"이라고 남겨 주시면 미팅에서 함께 정하겠습니다.

## 1. 사업 범위·일정·예산

가장 먼저 정해야 할 부분입니다. 범위와 마감이 정해져야 기술 방식과 견적이 나옵니다.

| No. | 질문 | 참고 (선택지·예시) | 답변 |
| --- | --- | --- | --- |
| 1-1 | 이번에 의뢰하실 개발 범위는 어디까지인가요? | ① 추천 기능 ② 인쇄물 생성 ③ 메인 사이트 전체 ④ 회원·결제 ⑤ 전화번호로 선물 보내기 (복수 선택) |  |
| 1-2 | 꼭 맞춰야 하는 오픈 일정이 있나요? 그 이유는 무엇인가요? | 예: 11월 말 시범 오픈, 지원사업 정산일, 행사·박람회 일정 |  |
| 1-3 | 정부·지자체 지원사업으로 진행되는 과제인가요? | 해당하면 사업명, 결과보고 양식, 요구 산출물(소스코드·매뉴얼 등) |  |
| 1-4 | 개발 예산 범위를 알려주실 수 있나요? | 범위만 알려주셔도 됩니다. 예산에 맞춰 단계별로 나눠 제안드립니다. |  |
| 1-5 | 오픈 후 매달 드는 운영비(AI 사용료, 서버, 도메인)는 누가 부담하나요? | AI 사용료는 추천·문구 생성 횟수에 따라 달라집니다. 예상 월 사용 건수를 알려주시면 계산해 드립니다. |  |
| 1-6 | 오픈 후 유지보수가 필요하신가요? | 기간(예: 3개월), 범위(오류 수정만 / 기능 추가 포함) |  |
| 1-7 | 프로젝트 의사결정권자와 연락 담당자는 누구인가요? | 디자인·문구 확인을 누가 최종 승인하는지 |  |

## 2. 쇼핑몰(카페24) 연동

추천 결과를 실제 구매로 연결하는 부분으로, 개발 난이도와 비용에 가장 크게 영향을 줍니다.

| No. | 질문 | 참고 (선택지·예시) | 답변 |
| --- | --- | --- | --- |
| 2-1 | 온답 사이트 전체를 카페24로 운영하시나요? | ① 전체가 카페24 쇼핑몰 ② 추천·카드 기능만 별도 웹사이트, 구매는 카페24 ③ 아직 미정 |  |
| 2-2 | 추천 결과 화면에서 구매까지 어느 정도로 이어져야 하나요? | ① 카페24 상품 상세 페이지로 이동 ② 선택한 수량대로 장바구니 담기 ③ 바로 주문서로 이동 |  |
| 2-3 | 상품의 가격·재고·사진을 카페24에서 자동으로 불러와야 하나요? | ① 자동 동기화 ② 온답 관리자에서 따로 입력 (상품 수가 적으면 ②도 충분합니다) |  |
| 2-4 | "10개 이상 10% 할인" 같은 수량 할인은 카페24에 설정되어 있나요? | 카페24 할인 설정을 쓸지, 온답 화면에서만 보여줄지 정해야 합니다. 할인 기준표가 있으면 보내주세요. |  |
| 2-5 | 카페24 관리자 계정을 개발자에게 공유하거나 개발자센터 앱 등록을 허용해 주실 수 있나요? | 카페24 API 연동에는 쇼핑몰 운영자 권한이 필요합니다. 부운영자 계정도 가능합니다. |  |
| 2-6 | 테스트용 쇼핑몰이나 실제 운영 중인 몰 주소가 있나요? | 실제 주문에 영향을 주지 않도록 테스트 환경을 선호합니다. |  |
| 2-7 | "전화번호만으로 선물 보내기"는 이번 범위에 포함인가요? | 포함이라면 카페24 선물하기 기능을 쓸지, 별도 서비스를 쓸지 함께 검토해야 합니다. |  |

## 3. 답례품 추천 시스템

행사 정보를 입력하면 상품 3개를 추천하는 기능입니다. 보내주신 관리자 시안의 점수 기준(희소성·장인 숙련도·지역 가치·격식 적합도)을 기본으로 검토하고 있습니다.

| No. | 질문 | 참고 (선택지·예시) | 답변 |
| --- | --- | --- | --- |
| 3-1 | 사용자가 입력하는 항목을 확정해 주세요. | 행사 유형, 답례 대상(관계), 예산(개당), 수량, 행사일·희망 배송일, 지역 선호, 알레르기·종교 등 제약 (추가·삭제 표시) |  |
| 3-2 | 추천은 어떤 방식을 원하시나요? | ① 관리자가 입력한 점수·태그로 규칙에 따라 추천 ② AI가 상황을 판단해 추천 ③ 규칙으로 후보를 고르고 AI가 추천 이유를 작성 (③을 권장합니다. 결과가 일관되고 설명하기 쉽습니다.) |  |
| 3-3 | "3개 추천"은 어떤 구성인가요? | ① 비슷한 수준 3개 ② 시안처럼 메인 1개 + 격식 단계별 비교 3개(실속 / 간소화 / 가벼운 안부) ③ 예산대별 3개 |  |
| 3-4 | 오픈 시점의 등록 상품 수는 몇 개이고, 1년 뒤에는 몇 개로 예상하시나요? | 현재 시안에는 5개가 등록되어 있습니다. |  |
| 3-5 | 조건에 맞는 상품이 없을 때는 어떻게 하길 원하시나요? | 예: 가장 가까운 상품 추천, 상담 문의 연결, 조건 완화 안내 |  |
| 3-6 | 관리자 점수(4개 항목, 40점 만점)와 행사·관계 태그는 누가 어떤 기준으로 입력하나요? | 기준표가 있으면 보내주세요. 항목이나 행사 유형을 더 추가할 계획이 있는지도 알려주세요. |  |
| 3-7 | 결과 화면의 "격식지수 85점", "1,185번 검토" 같은 숫자는 실제 계산으로 보여주길 원하시나요? | ① 실제 점수·검토 건수를 계산해 표시 ② 연출 문구로 사용. 근거 없는 수치는 표시·광고 규정에 걸릴 수 있어 ①을 권장합니다. |  |
| 3-8 | 추천 문구(ONDAP'S PICK)의 말투나 피해야 할 표현이 있나요? | 특히 장례 등 조심해야 하는 행사의 문구 기준 |  |

## 4. 인쇄물 자동생성

행사 정보로 택·엽서·스티커·띠지·카드를 만드는 기능입니다. 화면용 이미지가 아니라 실제 인쇄에 쓸 파일이라 인쇄 사양을 먼저 정해야 합니다.

제안 방식: AI 이미지 생성은 한글을 정확히 쓰지 못하고 인쇄 품질이 일정하지 않습니다. 그래서 **디자인 템플릿에 AI가 쓴 감사 문구와 이름을 넣고, 고객이 미리보기로 확인한 뒤 인쇄용 PDF를 만드는 방식**을 권장합니다.

| No. | 질문 | 참고 (선택지·예시) | 답변 |
| --- | --- | --- | --- |
| 4-1 | 인쇄는 누가, 어디서 하나요? | ① 자체 인쇄 ② 거래 중인 인쇄소 (업체명) ③ 미정 |  |
| 4-2 | 인쇄소의 작업 사양을 받아주실 수 있나요? | 파일 형식(PDF/AI), 색상 모드(CMYK), 해상도(300dpi), 재단 여백, 스티커 칼선 규칙 |  |
| 4-3 | 품목별 규격과 용도를 알려주세요. | 택 / 엽서 / 스티커 / 띠지 / 카드 각각의 크기(mm), 모양, 단면·양면 |  |
| 4-4 | 첫 오픈 때 꼭 필요한 품목은 무엇인가요? | 예: 카드와 띠지만 먼저, 나머지는 2단계 |  |
| 4-5 | "그림 생성"은 어떤 결과물을 생각하시나요? | ① 정해진 디자인에 문구·이름만 바뀜 ② 행사마다 다른 그림(일러스트) 생성 ③ 두 가지 모두. 참고할 예시 이미지가 있으면 보내주세요. |  |
| 4-6 | 디자인 템플릿은 누가 만드나요? | ① 온답 디자이너가 제공 ② 개발사가 제작(별도 비용) ③ 미정. 품목당 몇 종류가 필요한지도 알려주세요. |  |
| 4-7 | 사용할 글꼴과 브랜드 가이드(로고, 색상)가 있나요? | 글꼴은 상업 인쇄에 쓸 수 있는 라이선스가 필요합니다. |  |
| 4-8 | 인쇄 전 고객이 직접 문구를 수정하고 최종 승인하는 단계를 두실 건가요? | 이름·날짜 오타 분쟁을 막기 위해 필수로 권장합니다(특히 장례 답례품). |  |
| 4-9 | 만들어진 인쇄 파일을 어떻게 주문과 연결하고 전달받으시겠어요? | ① 온답 관리자에서 주문별로 내려받기 ② 인쇄소에 자동 전달 ③ 카페24 주문 메모에 파일 링크 |  |
| 4-10 | 감사 카드를 인쇄 없이 모바일 카드(이미지·링크)로도 보낼 수 있어야 하나요? | 메인 화면의 "AI 감사 카드 만들기"가 인쇄용인지 모바일용인지 확인이 필요합니다. |  |

## 미팅 전 보내주실 자료

있는 것만 보내주셔도 됩니다. 미리 받으면 미팅에서 구체적인 방식과 견적을 바로 말씀드릴 수 있습니다.

- [ ] 카페24 쇼핑몰 주소와 테스트용 관리자 계정(또는 부운영자 계정)
- [ ] 등록 예정 상품 목록(상품명, 가격, 카페24 상품 번호, 점수·태그)
- [ ] 수량 할인 기준표
- [ ] Claude로 만든 프로토타입 소스코드

- [ ] 인쇄물 실물 사진 또는 참고 예시(택, 엽서, 스티커, 띠지, 카드)
- [ ] 인쇄소 작업 사양서
- [ ] 브랜드 가이드(로고 파일, 색상, 글꼴)
- [ ] 지원사업일 경우 사업계획서의 개발 관련 부분과 성과지표
