# 격식지수 v2 엔진 및 가상 상품 3개

사용자 요청: 출원서 검토 후 격식지수 엔진을 먼저 구현하고 상품 근거 3개를 샘플로 만들어 검증한다. 관련 문서는 docs/FORMALITY-V2-PILOT.md.

- src/engine/eligibility.ts: 행사 격식, 근거 기반 상품 희소값, 허용 구간 필터, 통과 후보 순위, 전체 판단과 재현용 스냅샷.
- src/engine/formality-samples.ts: 전부 가상의 차도구·장류·곡물 간식. 실제 인증·생산자 자료로 사용하면 안 된다.
- /admin/formality: 기존 관리자 권한으로 검증. 현재 카탈로그와 가상 자료 분리, 기준/근거 편집, JSON 내보내기/불러오기.
- 관리 화면 입력은 메모리 전용이며 DB 저장·중앙 정책 게시 기능이 아니다. 새로고침 전에 파일로 내보내야 한다.
- 고객용 recommend(), /result, 기존 점수·상품 데이터·SQL·결재·주문은 변경하지 않았다. 실속/표준/격식 역할별 구성과 자동 학습도 이번 범위에 포함하지 않는다.
- 고격식 샘플은 행사 85, 희소 하한 0.7. 차도구 0.86·장류 0.74 통과, 간식 0.28 제외. 낮은 격식에서는 세 상품 통과.
- npm run formality:sample, node --test test/eligibility.test.ts, node scripts/e2e/formality.mjs.
- 테스트·타입·빌드 통과. 다음은 실제 근거 검수 및 정책 보정, 중앙 저장/게시와 전체 호출 경로의 단계적 전환이다.

검토·개발 범위는 온답/포춘크래프트다. 뉴로렌즈는 관련 없으며 사용자가 명확히 제외했다.
